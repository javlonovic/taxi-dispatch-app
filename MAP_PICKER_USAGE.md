# Использование выбора местоположения на карте

Этот документ описывает, как использовать новую функциональность выбора местоположения на карте в приложении такси.

## Обзор

Система выбора местоположения включает в себя:

1. **LocationMapPicker** - виджет для выбора местоположения на карте с поиском
2. **LocationConfirmationDialog** - диалог подтверждения выбранного местоположения
3. **GeocodingService** - сервис для работы с геокодированием адресов
4. Интеграция с экраном заказа такси

## Основные компоненты

### LocationMapPicker

Интерактивная карта для выбора местоположения с функциями:
- Отображение карты OpenStreetMap
- Поиск адресов с автодополнением
- Выбор местоположения касанием по карте
- Определение текущего местоположения GPS
- Геокодирование координат в читаемые адреса

### LocationConfirmationDialog

Диалог подтверждения с информацией:
- Выбранный адрес
- Координаты местоположения
- Кнопки подтверждения/отмены

### GeocodingService

Сервис для работы с адресами:
- Прямое геокодирование (адрес → координаты)
- Обратное геокодирование (координаты → адрес)
- Поиск адресов с предложениями
- Проверка местоположения в пределах Ташкента

## Как использовать

### 1. Базовое использование

```dart
// Открыть карту для выбора местоположения
final result = await Navigator.of(context).push<SelectedLocation>(
  MaterialPageRoute(
    builder: (context) => LocationMapPicker(
      title: 'Выберите место отправления',
      confirmButtonText: 'Выбрать это место',
      onLocationSelected: (selectedLocation) {
        Navigator.of(context).pop(selectedLocation);
      },
    ),
  ),
);

if (result != null) {
  // Использовать выбранное местоположение
  print('Адрес: ${result.address}');
  print('Координаты: ${result.geoPoint.latitude}, ${result.geoPoint.longitude}');
}
```

### 2. С начальным местоположением

```dart
final result = await Navigator.of(context).push<SelectedLocation>(
  MaterialPageRoute(
    builder: (context) => LocationMapPicker(
      initialLocation: GeoPoint(41.2995, 69.2401), // Центр Ташкента
      title: 'Выберите место назначения',
      onLocationSelected: (selectedLocation) {
        Navigator.of(context).pop(selectedLocation);
      },
    ),
  ),
);
```

### 3. С диалогом подтверждения

```dart
// После получения результата от карты
if (result != null) {
  final confirmed = await showLocationConfirmationDialog(
    context: context,
    title: 'Подтвердите место отправления',
    address: result.address,
    location: result.geoPoint,
    subtitle: 'Водители будут искать вас по этому адресу',
  );

  if (confirmed) {
    // Местоположение подтверждено
    setState(() {
      _selectedLocation = result;
    });
  }
}
```

## Интеграция в заказ такси

В экране заказа такси (`enhanced_ride_request_screen.dart`) добавлена опция "Выбрать на карте":

1. Пользователь нажимает на поле местоположения
2. Появляется диалог с опциями:
   - Текущее местоположение (GPS)
   - Адрес филиала
   - **Выбрать на карте** (новая опция)
3. При выборе "Выбрать на карте" открывается `LocationMapPicker`
4. После выбора показывается диалог подтверждения
5. При подтверждении местоположение сохраняется

## Демо экран

Для тестирования функциональности создан демо экран:
- Доступен через кнопку "Тест выбора местоположения" на главном экране компании
- Позволяет выбрать место отправления и назначения
- Показывает сводку выбранных местоположений

## Технические детали

### Зависимости

- `flutter_map` - для отображения карты
- `latlong2` - для работы с координатами
- `geocoding` - для геокодирования адресов
- `geolocator` - для определения текущего местоположения

### Провайдеры

- `geocodingServiceProvider` - провайдер для сервиса геокодирования

### Модели данных

```dart
class SelectedLocation {
  final GeoPoint geoPoint;    // Координаты
  final String address;       // Читаемый адрес
  final String? name;         // Опциональное название
}

class LocationResult {
  final GeoPoint geoPoint;    // Координаты
  final String address;       // Адрес
  final String originalQuery; // Исходный поисковый запрос
}
```

## Особенности

1. **Русский язык** - все интерфейсы на русском языке
2. **Геокодирование** - автоматическое преобразование координат в адреса
3. **Поиск адресов** - поиск с задержкой для оптимизации запросов
4. **Подтверждение** - обязательное подтверждение выбранного местоположения
5. **Fallback** - если геокодирование не работает, показываются координаты
6. **Ташкент-ориентированность** - оптимизировано для работы в Ташкенте

## Возможные улучшения

1. Кэширование результатов геокодирования
2. Сохранение часто используемых адресов
3. Интеграция с Google Places API для более точного поиска
4. Добавление категорий мест (дом, работа, и т.д.)
5. Офлайн карты для работы без интернета

## Устранение неполадок

### Проблемы с геокодированием
- Проверьте интернет-соединение
- Убедитесь, что координаты находятся в пределах Узбекистана

### Проблемы с GPS
- Проверьте разрешения на местоположение
- Убедитесь, что GPS включен на устройстве

### Проблемы с картой
- Проверьте интернет-соединение для загрузки тайлов карты
- Убедитесь, что flutter_map правильно настроен
