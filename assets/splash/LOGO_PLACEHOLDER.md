# Splash Screen Logo Placeholder

## Required File

Please add the following splash screen logo file to this directory:

### splash_logo.png
- Recommended size: 512x512 px or larger
- PNG format with transparent background
- Will be displayed on white background (#FFFFFF)
- Should be centered and clearly visible

## Design Guidelines

- Keep the logo simple and recognizable
- Ensure good contrast against white background
- Logo should work well at various screen sizes
- Avoid text that's too small to read

## How to Add Your Splash Logo

1. Save your splash logo as:
   - `assets/splash/splash_logo.png`

2. Run the splash screen generator:
   ```bash
   flutter pub run flutter_native_splash:create
   ```

3. Rebuild the app:
   ```bash
   flutter clean
   flutter pub get
   flutter run
   ```
